# Testes v1.1.6

1. Preview: use a roda do mouse sobre uma textura, arraste com o botão esquerdo e dê duplo clique para voltar ao fit automático.
2. Batch Replace: use arquivos `0.png`, `1.png` etc. e também arquivos cujo nome-base seja igual ao Title da textura. Confirme que índices acima de 149 funcionam.
3. Backup: antes do primeiro Replace/Remove/Add/Color Depth, confirme a criação de `<arquivo>.tpl.bak`. Outras alterações na mesma sessão não devem criar nomes adicionais.
4. Recent Files: abra alguns TPLs, reinicie o programa e confira File > Recent files. Arquivos apagados devem ser removidos da lista ao serem clicados.
