# RE4 PS2 TPL Manager v1.1.0

## Objetivo

Esta versão é uma refatoração estrutural. O objetivo é reduzir a responsabilidade do `FrmMain` e criar uma base mais segura para novas funcionalidades sem alterar intencionalmente o fluxo visual da aplicação.

## 1. Serviços extraídos do FrmMain

### `Core/Services/TplReader.cs`
- Fonte única para leitura de cabeçalho global, cabeçalho de textura, pixels, CLUT e mipmaps.
- Substitui as duas versões duplicadas de `ReadTexture` que existiam em `FrmMain`.
- Valida índice, offsets e fim de arquivo antes de ler dados.
- Centraliza cálculo de tamanho de pixels e paleta para 4-bit, 8-bit e 32-bit.

### `Core/Services/TextureDecoder.cs`
- Isola o decoder usado pelo preview da camada WinForms.
- Hoje delega ao decoder PS2 otimizado já existente (`TplHelper`), mas cria o ponto único para futuras melhorias de decode sem acoplar a UI.

### `Core/Services/TplWriter.cs`
- Criação de TPL vazio.
- Rebuild/atualização de offsets.
- Substituição binária de textura.
- Preserva vínculo/metadados de mipmaps da textura de destino durante Replace.

O formulário continua responsável por UI, diálogos e comandos do usuário, mas delega parsing e operações binárias principais aos serviços.

## 2. Parsing centralizado

`FrmMain.ReadTexture(...)` agora é apenas um adaptador para `TplReader`. O parsing duplicado foi removido. O fluxo de Replace também usa `TplReader` para ler o arquivo substituto.

Correções incluídas:
- 4-bit: `width * height / 2` bytes de pixels e `0x80` bytes de CLUT.
- 8-bit: `width * height` bytes de pixels e `0x400` bytes de CLUT.
- 32-bit: `width * height * 4` bytes de pixels e nenhuma CLUT.
- Leituras truncadas/offsets inválidos agora produzem erro explícito em vez de continuar com buffers incompletos.

## 3. Escrita/rebuild refatorados

O antigo `UpdateAllOffsets` do formulário foi substituído pelo serviço de escrita, com um único `FileStream` de leitura/escrita durante o rebuild. Isso remove dezenas de ciclos de abrir/fechar o mesmo arquivo.

O Replace deixou de remontar manualmente `part1/part2/part3/part4` no formulário. Essa cirurgia agora pertence a `TplWriter.ReplaceTexture`.

Também foi corrigido o cálculo de tamanho para pixels 32-bit durante rebuild e o offset de paleta passa a ser zero para formatos sem CLUT.

## Compatibilidade

A UI, os atalhos e o fluxo geral permanecem os mesmos da Etapa 2.1. Conversores BMP/TGA e rotinas específicas de mipmaps ainda são legadas e serão bons candidatos para etapas posteriores.
