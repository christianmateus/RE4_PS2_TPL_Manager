# v1.1.0 Hotfix - TPL model ambiguity

Corrige erro CS1061 nos novos serviços (`pixels`, `palette`, `header` e demais campos do modelo).

## Causa
Existiam dois tipos com o nome `TPL` no namespace principal:
- `TPLDefinition.TPL`: modelo completo usado pelo manager.
- `TPL` em `ConverterBMP.cs`: estrutura legada do conversor, sem buffers `pixels/palette/header`.

Os novos serviços podiam resolver o segundo tipo por ambiguidade de nome.

## Correção
- A classe legada foi renomeada para `LegacyTplHeader`.
- `TplReader`, `TplWriter` e `TextureDecoder` usam explicitamente `TPLDefinition.TPL` através do alias `TplModel`.
- Nenhuma funcionalidade do conversor foi removida.
