# RE4 PS2 TPL Manager v1.1.2

## In-memory texture pipeline

- Added `Core/Services/TextureEncoder.cs`.
- PNG/BMP/TGA replacement no longer needs `.temp/*.bmp` or `.temp/0_*.tpl`.
- Increase Color Depth (256 colors) and Decrease Color Depth (16 colors) encode directly from the loaded texture.
- Increase/Decrease All use the same in-memory pipeline.
- Apply Changes encodes the edited preview directly in memory.
- `TplWriter` now accepts an in-memory `TPLDefinition.TPL` replacement.
- `TplWriter.WriteSingleTexture` writes standalone TPL files without routing through temporary files.

## ConverterBMP architecture

`ConverterBMP.BMPtoTPL` is now a legacy adapter. Header creation, indexed-image encoding and TPL writing are delegated to `TextureEncoder` + `TplWriter`. This removes duplicated TPL-header construction from that method and makes the conversion pipeline reusable by the UI.

`TPLtoBMP` remains legacy code for now; some extraction/mipmap/EFF utilities still use `.temp` and should be migrated separately to avoid mixing a risky binary-layout rewrite into this release.

## Safer dialogs

File/folder menu actions now check the result of the dialog before opening/reading a path. Cancelling no longer attempts to access an empty filename. PNG to TPL is now a complete, cancel-safe conversion action and writes to `Converted/`.

## Automatic refresh

Replacement, color-depth changes, Apply Changes, batch replace and transparency changes refresh the table after the file is updated while trying to preserve the current selection.
