# RE4 PS2 TPL Manager v1.1.3

## Temporary-file cleanup

- Removed the fixed `.temp` directory from application startup and shutdown.
- `ReplaceMipmaps` now resizes and encodes mipmaps in memory through `TextureEncoder`; no BMP is written and reopened.
- `Convert all to BMP` now exports directly from the TPL decoder into `Converted/<tpl name>/`.
- `ConverterBMP.TPLtoBMP` was reduced to a decoder/export adapter and no longer maintains hidden 16/256-color BMP caches.
- EFF extraction now reads the embedded HEFF/index chunk from `MemoryStream` and writes only the final extracted TPL files.
- The EFF offset table now starts after the file-count field, avoiding the legacy four-byte offset error.
- `BMPtoTPL(..., isTemp: true)` remains source-compatible for old callers, but uses the operating-system temporary directory rather than an application-local folder. No current UI flow depends on it.

## Mipmaps

Mipmaps are encoded using the bit depth already declared by each existing mipmap header (4-bit or 8-bit). The routine validates payload size and file bounds before overwriting pixels. This release deliberately does not change mipmap layout or add/remove mipmap headers.
