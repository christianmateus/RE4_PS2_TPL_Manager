# v1.1.3 Hotfix 1

## Export All to PNG

- PNG export no longer requantizes decoded textures to 256 colors. PNG is saved directly from the decoded bitmap, preserving full decoded color/alpha data and removing an unnecessary failure point.
- A failure in one texture no longer aborts the entire export loop. Remaining texture indices continue to be exported.
- If one or more entries fail, the UI reports their texture indices and error messages after the export finishes.
- The menu no longer swallows export exceptions silently.
- Added a guard for an empty/invalid current TPL path.
