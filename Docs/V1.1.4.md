# RE4 PS2 TPL Manager v1.1.4

## Transparency-safe color depth conversion

- `TextureEncoder.EncodeImage` no longer quantizes through an indexed BMP.
- Palette indices and PS2 CLUT data are generated directly from the source ARGB pixels.
- The PS2 alpha range (0x00-0x80) is written from the original PC alpha range (0x00-0xFF).
- 4-bit <-> 8-bit color depth conversion now preserves transparent and semi-transparent palette entries.
- Quantization is alpha-aware: transparency participates in palette splitting instead of being discarded.
- Fully transparent texels are normalized to transparent black so invisible RGB values do not waste palette entries.

The change also benefits PNG/BMP/TGA import and Apply Changes because these paths share the same in-memory encoder.
