# RE4 PS2 TPL Manager v1.1.5

## UX / interface improvements

- Right-clicking a texture now visually selects the complete row before the context menu is opened.
- The texture title/name column is read-only.
- Added `TexturePreviewBox`, a preview control designed for game textures:
  - checkerboard transparency background;
  - integer nearest-neighbor zoom for small textures, avoiding blur;
  - centered fit-to-window for textures larger than the viewport;
  - compact resolution / zoom indicator.
- Status bar feedback was expanded and standardized across important operations such as open, refresh, save, extract, add, compile, replace, color-depth conversion, export, remove and batch operations.
- Selecting a texture now shows its index, resolution and bit depth in the status bar.

The texture decoding/encoding logic from v1.1.4 was intentionally left unchanged.
