# v1.1.5 Hotfix 1

Corrige o erro CS0234 no WinForms Designer relacionado a `RE4_PS2_TPL_Manager.UI.Controls.TexturePreviewBox`.

O controle permanece fisicamente em `UI/Controls/TexturePreviewBox.cs`, mas passa a usar o namespace raiz `RE4_PS2_TPL_Manager`, o mesmo de `FrmMain`. Isso evita problemas de resolução de namespace em projetos WinForms/.NET Framework antigos sem alterar a organização de pastas.
