# RE4 PS2 TPL Manager v1.1.7

## Batch Replace 4-bit / 8-bit
- Batch Replace no longer asks for 16/256 colors for every true-color PNG/BMP/TGA.
- The replacement automatically preserves the destination texture color depth:
  - destination 4-bit -> encode with 16 colors;
  - destination 8-bit -> encode with 256 colors.
- Batch mode is non-interactive after selecting the folder.
- Multi-texture TPL sources use texture index 0 during batch.
- Mipmap confirmation dialogs are not shown during batch operations.
- Status bar reports how many 4-bit and 8-bit textures were replaced.

## Create Empty TPL
- Removed the legacy fixed `temp.tpl` workflow.
- Creating an empty TPL now opens a Save File Dialog first.
- Default suggested filename: `new_texture_pack.tpl`.
- `.tpl` extension is applied automatically and overwrite confirmation is enabled.
- The created TPL immediately becomes the current file and is added to Recent Files.
- Cancelling the dialog creates no file.

## Windows application
- Project OutputType changed from `Exe` to `WinExe`.
- The application no longer opens a console window when launched normally.
