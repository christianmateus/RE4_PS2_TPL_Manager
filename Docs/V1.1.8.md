# RE4 PS2 TPL Manager v1.1.8

## Batch Replace color-depth modes

Batch Replace now opens a dedicated dark-themed dialog before folder selection.

Available modes:

- **Preserve TPL color depth (recommended)**: each imported image follows the current destination texture; 4-bit stays 4-bit and 8-bit stays 8-bit.
- **Force 4-bit (16 colors)**: every imported PNG/BMP/TGA/JPG/JPEG is encoded as a 16-color / 4-bit texture.
- **Force 8-bit (256 colors)**: every imported PNG/BMP/TGA/JPG/JPEG is encoded as a 256-color / 8-bit texture.

TPL source files continue to be copied as TPL textures, so the batch color-depth mode does not rewrite their internal format.

The chosen mode is shown in the status bar during and after the operation. Batch replacement remains non-interactive after the initial mode/folder selection.

## Other adjustments

- Added JPG/JPEG to the actual image replacement path (they were already discovered by Batch Replace but were previously rejected by Replace).
- Application/assembly version updated to 1.1.8.
