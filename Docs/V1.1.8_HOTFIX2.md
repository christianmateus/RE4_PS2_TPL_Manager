# v1.1.8 Hotfix 2

## DataGridView metadata safety

- `Bit Depth` is now a read-only text column.
- `Interlace` is now a read-only text column.
- Removed per-row `DataGridViewComboBoxCell` instances for both fields.
- The values continue to be displayed from the TPL metadata loaded from disk.
- Real color-depth changes must continue through Increase/Decrease Color Depth, which rebuilds the pixel/CLUT payload correctly.

This prevents accidental header-only edits that could make the displayed metadata inconsistent with the texture payload.
