# v1.2.0

## Interlace preservation

The in-memory texture pipeline now preserves the destination TPL interlace value during image replacement and color-depth conversion. New images are quantized first, then their indexed payload is converted to the original BGRA or PS2 layout before TplWriter rebuilds the file.

Covered flows:

- Replace PNG/BMP/TGA
- Batch Replace PNG
- Increase Color Depth
- Decrease Color Depth
- Increase All / Decrease All
- Apply Changes
- Replace mipmaps (uses each mipmap header interlace)

Values 0 and 1 keep linear payloads and preserve the exact header flag. Values 2 and 3 use the validated PS2 swizzle and preserve the exact Normal/Inverted flag.

## Convert Interlace

`Tools > Convert Interlace...` is promoted from experimental to a normal tool after successful in-game BGRA -> PS2 -> BGRA validation. Safety restrictions remain for 4-bit sizes not covered by the validated mapping and for mipmapped textures.
