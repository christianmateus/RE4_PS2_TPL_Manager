# RE4 PS2 TPL Manager v1.3.0

## Mipmap Editor

Double-click any texture row to open the new **Texture & Mipmap Editor**. The window shows Main, Mip 1 and Mip 2 side-by-side using the same zoom/pan preview control as the main window.

### Shared CLUT rules

RE4 PS2 mipmaps share the parent texture palette. The v1.3.0 pipeline therefore treats Main + Mip 1 + Mip 2 as one texture family:

- Replacing an individual mipmap never creates or changes a CLUT.
- The imported image is mapped to the closest entries in the parent CLUT, including alpha distance.
- Regenerate Mipmaps resizes the Main texture and maps both levels to the same parent CLUT.
- Replacing Main from the mipmap editor creates the new Main CLUT and automatically regenerates existing mipmaps against it.

### Add / Remove

**Add Mipmaps** creates two levels at 1/2 and 1/4 resolution. New mipmap headers and payloads are inserted through a complete TPL rebuild.

Generated interlace follows the layout observed in RE4 PS2 assets: compatible large PS2 levels retain PS2 swizzle; smaller levels use linear BGRA.

**Remove Mipmaps** removes both mip headers and payloads and rebuilds every affected offset.

## Writer changes

`TplWriter.RebuildFile()` now supports the canonical RE4 layout:

1. global header
2. main texture headers
3. mipmap headers
4. main pixels + CLUTs
5. mipmap pixels

The rebuild algorithm was verified against `r100_04.tpl`: a no-op rebuild reproduced the original 646,528-byte file byte-for-byte.
