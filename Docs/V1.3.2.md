# RE4 PS2 TPL Manager v1.3.2

## Texture editor refresh
- Quick Adjustments are now non-destructive/non-cumulative. Every change is recalculated from the editor base image.
- Brightness, Contrast, Saturation, Hue, Sharpen and Pixelate now have sliders plus numeric values.
- Rotate/Flip/Resize/Filters/Layers update the editor base and the active quick adjustments are reapplied.
- Reset restores the selected texture and zeroes all quick adjustments.
- Apply Changes remains the explicit write-to-TPL action and regenerates existing mipmaps.
- Editor layout was reorganized into Quick Adjustments, Transform, Filters and Layers with a cleaner dark UI.
- Added an unsaved-changes indicator in the editor.
